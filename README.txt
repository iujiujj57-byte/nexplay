NEXPLAY — READY-TO-UPLOAD FILES

Upload these files into the ROOT of the GitHub Pages repository (the same folder as index.html):
- index.html
- style.css
- script.js
- banned.html

Also included: firestore.rules. This is NOT a website file. It is the rules text to paste into Firebase Console > Firestore Database > Rules, then Publish. If you already published these exact rules, do not change them.

IMPORTANT
- This package uses the existing NexPlay Firebase project nexplay-1029b.
- Visitors use anonymous sign-in; they do not create email/password accounts.
- Administrator sign-in uses the existing email arehq@schools.vic.edu.au. Never put the password in a website file.
- The administrator email must be verified in Firebase Authentication.
- Keep all four website files together in the repository root. File names are case-sensitive.
- Do not upload the folder itself as a nested directory; upload the four website files at the same level as your current index.html.

After uploading, wait for GitHub Pages to redeploy, then refresh the website with Ctrl+Shift+R.
